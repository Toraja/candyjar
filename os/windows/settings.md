# Settings

## Time & language

### Language & region
- Windows display language: `English (Australia)`
- Preferred languages (order as below)
  - English (Australia)
    - Install all `Language features`
  - Japanese
    - Install all `Language features`
    - Keyboard layout: `English keyboard (101/102 key)`
- Country or region: `Australia`
- Regional Format: `English (Australia)`

### Date & time
- Format
  - Short date: `05/04/2017`
  - Short time: `09:40 / 14:40`
  - Long time: `09:40:07 / 14:40:07`

- Personalise lock screen: `Picture`

- Show recommended files in Start...: `Off`

### Taskbar

## System

### Display

- Brightness: `100%`
- Night light: Schedule night light -> 20:00 to 06:00

### Notifications

- Notifications
  - Show notification bell icon: `On`

### Power & battery

- Power mode
  - Plugged in: `Best performance`
  - On battery: `Balanced`
- Screen, sleep & hibernate time-outs: As you like
- Energy saver
  - Turn energy saver on automatically when battery level is at: `20%`
- Lid & power button controls
  - Plugged in
    - Closing the lid will make my PC: `Do nothing`
  - On battery
    - Closing the lid will make my PC: `Do nothing`

### Multitasking

- Show tags from apps when snapping or pressing `Alt + Tab`: `Don't show tabs`

### Advanced

- End Task: `On`
- File Explorer

### Clipboard

- Clipboard history: `On`
